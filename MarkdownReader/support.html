Frequently Asked Questions

Which files can I open?

Markdown files (.md, .markdown) and folders containing them. Open a folder to browse all its Markdown files in a tree sidebar.

How do I make it the default Markdown app?

Right-click any .md file in Finder → Get Info → Open with → choose AI Doc Reader → Change All.

Why is the version history empty?

Version history works for files inside a Git repository. Open the repository's root folder so the app can find the Git data.

Are diagrams and math supported?

Yes — Mermaid diagrams, KaTeX math and syntax-highlighted code blocks render automatically.

Does the app modify my files?

Never. AI Doc Reader is a pure reader and opens your documents in read-only mode.

どのファイルを開けますか?

Markdownファイル(.md、.markdown)とそれらを含むフォルダに対応しています。フォルダを開くと、サイドバーにツリー表示されます。

Markdownのデフォルトアプリにするには?

Finderで.mdファイルを右クリック → 情報を見る → このアプリケーションで開く → AI Doc Readerを選択 → 「すべてを変更」をクリックしてください。

バージョン履歴が表示されません

バージョン履歴はGitリポジトリ内のファイルで利用できます。リポジトリのルートフォルダを開いてください。

図や数式は表示できますか?

はい。Mermaid図、KaTeX数式、シンタックスハイライト付きコードブロックを自動で表示します。

ファイルが変更されることはありますか?

ありません。AI Doc Readerは閲覧専用アプリで、ファイルを読み取り専用で開きます。

常见问题

可以打开哪些文件?

Markdown 文件(.md、.markdown)以及包含它们的文件夹。打开文件夹后,侧边栏会以树状结构展示全部 Markdown 文件。

怎么设为 Markdown 默认打开方式?

在 Finder 中右键任意 .md 文件 → 显示简介 → 打开方式 → 选择 AI Doc Reader → 点击「全部更改」。

为什么版本历史是空的?

版本历史功能适用于 Git 仓库内的文件。请打开仓库的根目录,应用才能读取 Git 数据。

支持图表和公式吗?

支持。Mermaid 图表、KaTeX 数学公式、语法高亮代码块都会自动渲染。

应用会修改我的文件吗?

绝不会。AI Doc Reader 是纯阅读器,以只读方式打开文档。
